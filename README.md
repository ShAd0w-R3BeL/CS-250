CS 250: Software Development Life Cycle

This repository contains my assignments for CS 250: Software Development Life Cycle. This course focuses on the principles of the Software Development Life Cycle (SDLC) and its application within an agile development environment, specifically using Scrum. The assignments within this repository demonstrate my understanding of various roles and processes in a software development team.

Assignments and Artifacts
This portfolio includes work that reflects my application of key concepts learned in the course, such as:

Scrum Events: Documentation and reflections on daily stand-ups, sprint planning, and retrospectives.

User Stories: The creation and refinement of user stories to capture and prioritize project requirements.

Test Cases: The development of detailed test cases to ensure software quality and functionality.

Journal Entries: Reflections on the roles of a Scrum Master, Product Owner, Tester, and Developer, as well as communication and project management tools.

Assignment 3-2: User Stories: Here, I have documented user needs and translated them into actionable user stories for a development team.
